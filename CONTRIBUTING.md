# Как внести вклад

Easy Peasy DLS находится в Public Preview. Сейчас особенно полезны небольшие изменения, которые уменьшают процессный шум, делают проверку надёжнее или улучшают работу на разных технологических стеках.

## Перед изменением

1. Проверьте существующие Issues.
2. Для нового поведения сначала создайте Issue и опишите пользовательскую проблему.
3. Не добавляйте обязательный документ, gate, агента или модельный вызов без конкретного failure mode, который он предотвращает.
4. Не включайте в examples реальные пути, секреты, логи или материалы из закрытых репозиториев.

## Локальная проверка

Требуется Python 3.11 или новее. Внешние Python-зависимости не нужны.

```sh
python3 plugins/dls/scripts/run_tests.py
python3 scripts/validate_public_repo.py
```

Если вы меняли skills или plugin manifest, дополнительно запустите актуальные validators из установленного Codex SDK/системных skills.

## Pull request

В PR коротко укажите:

- какую пользовательскую проблему решает изменение;
- почему существующий путь был недостаточен;
- какие проверки выполнены;
- меняются ли state, schemas, approvals, review или совместимость старых artifacts.

Мы предпочитаем небольшой проверяемый diff большой перестройке «на будущее».
