# Безопасность

Пожалуйста, не публикуйте сведения об уязвимости в обычном Issue.

Используйте **Private vulnerability reporting** на странице Security этого репозитория. Укажите:

- затронутую версию;
- минимальный сценарий воспроизведения;
- возможное влияние;
- затронуты ли approvals, command execution, path integrity, review provenance или секреты.

Не прикладывайте реальные токены, приватный исходный код и пользовательские данные. Получение сообщения будет подтверждено через GitHub, после чего мы согласуем безопасный способ проверки и публикации исправления.

## Модель доверия

DLS обрабатывает локальные Git-репозитории и запускает repository-owned validation commands. Поэтому особенно важны сообщения об обходе argv-only execution, path traversal, подмене ReviewPack/ReviewIR, stale evidence, ошибочной записи human approval и утечке данных из `.dls/cache`.
